# galeria-angular

Galería fotográfica interactiva desarrollada como Single Page Application en Angular. Permite explorar colecciones por categoría, filtrar por texto en tiempo real y visualizar imágenes en alta resolución con controles por teclado.

## Demo

[erevilladev.github.io/galeria-angular](https://erevilladev.github.io/galeria-angular/)

## Setup

```bash
git clone https://github.com/erevilladev/galeria-angular.git
cd galeria-angular
npm install
npm start
```

La aplicación quedará disponible en `http://localhost:4200`.

### Build y Despliegue

```bash
npm run build:gh
npm run deploy
```

## Stack

- Angular 19+ (Standalone Components, Signals, Control Flow nativo)
- TypeScript
- CSS puro con diseño adaptativo (CSS Grid y Flexbox)
- Despliegue en GitHub Pages via `angular-cli-ghpages`

## Créditos

Fotografía cortesía de creadores independientes en [Unsplash](https://unsplash.com).
